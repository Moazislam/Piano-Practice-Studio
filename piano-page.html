About the sound & keyboard

Grand-piano recordings: Salamander Grand Piano by Alexander Holm, a Yamaha C5, distributed under CC BY 3.0. This instrument uses 21 embedded MP3 recordings, pitch-shifted to adjacent notes, with adjustable gain, filtering, release and room reverb. Touch changes volume and tone; this is a single sampled velocity layer. No internet connection is needed to play. Computer keyboards may limit simultaneous key presses; touch input supports multiple fingers. Settings are saved in this browser when storage is available.
